> Browser extensions that are actually useful. Curated, simple, and free to use - one line per entry.


## Why This List
"What extensions do you use?" is asked constantly on Reddit and X. A short, opinionated list - not 300 entries - gets saved and reshared. Dead simple to maintain.

## Privacy and Safety
| Extension | What it does |
| --- | --- |
| [uBlock Origin](https://github.com/gorhill/uBlock) | The ad blocker to start with |
| [Bitwarden](https://bitwarden.com/) | Passwords, synced and free |
| [Privacy Badger](https://privacybadger.org/) | Blocks invisible trackers |
| [Ghostery](https://www.ghostery.com/) | Blocks ads and shows trackers |
| [DuckDuckGo](https://duckduckgo.com/) | Tracker blocking and private search |
| [ClearURLs](https://github.com/ClearURLs/Addon) | Strips tracking parameters from URLs |
| [Cookie Away](https://www.cookieaway.com/) | Rejects cookie banners for you, free and open source |

## Contributing
See CONTRIBUTING.md. The short version: fork this repo, add your entry as one line in the right table, open a pull request. Rules: the extension must be free, popular, and actually useful. No trial-only extensions. One entry per extension.
